# راهنمای فاین‌تیون مدل تشخیص PPE

هدف: مدلی که **در محیط و دوربین‌های خود شما** کلاه ایمنی و لباس کار را دقیق تشخیص بدهد.
مدل آماده تقریباً همیشه روی لباس‌های متفاوت، نورهای ضعیف و زاویه‌های دوربین شما ضعیف‌تر از مدل فاین‌تیون‌شده است.

> همه دستورها را از ریشه پروژه اجرا کنید. نیازمندی: `pip install -r requirements.txt`

## ۱) کلاس‌ها
مدل باید این پنج کلاس را داشته باشد (نام‌ها در `data.yaml`؛ برنامه حروف بزرگ/کوچک و فاصله/خط‌تیره را نادیده می‌گیرد):

| شناسه | کلاس | چه چیزی را کادر بزنید |
|---|---|---|
| 0 | `Person` | کل بدن فرد |
| 1 | `Hardhat` | کلاه ایمنی روی سر |
| 2 | `NO-Hardhat` | سرِ بدون کلاه (فقط خودِ سر) |
| 3 | `Safety Vest` | لباس کار / جلیقه روی بدن |
| 4 | `NO-Safety Vest` | بدنِ بدون لباس کار (قسمت تنه) |

نکته: کلاس‌های `NO-*` اختیاری‌اند. اگر فقط `Person/Hardhat/Safety Vest` را برچسب بزنید، برنامه «نبودنِ» کلاه/لباس را تخلف حساب می‌کند.
برچسب‌گذاری `NO-*` دقت را بالاتر می‌برد، چون مدل صریحاً یاد می‌گیرد سر بدون کلاه چه شکلی است.

## ۲) جمع‌آوری تصویر (۳۰۰ تا ۱۰۰۰ تصویر برای شروع)
```bash
python training/collect_frames.py --source 0 --every 2 --count 300
python training/collect_frames.py --source rtsp://user:pass@192.168.1.20/stream1 --every 5 --count 500
```
تصاویر در `training/dataset/raw_images/` ذخیره می‌شوند. تنوع مهم‌تر از تعداد است:
- نور روز، شب، سایه و نور مستقیم
- فاصله‌ها و زاویه‌های مختلف دوربین
- افراد مختلف و کلاه‌های رنگی مختلف
- **نمونه‌های منفی**: افراد بدون کلاه، بدون لباس کار، و فقط با یکی از آن‌ها
- افراد پشت‌به‌دوربین، نشسته، خم‌شده و تا حدی پشت اجسام

همچنین هر آلارمی که در داشبورد «هشدار کاذب» بزنید، فریم خام آن در `data/feedback/` ذخیره می‌شود. این‌ها دقیقاً همان
حالت‌هایی‌اند که مدل اشتباه می‌کند؛ آن‌ها را برچسب بزنید و به دیتاست اضافه کنید (مهم‌ترین منبع بهبود).

## ۳) برچسب‌گذاری
ابزارهای رایگان: [Label Studio](https://labelstud.io)، [CVAT](https://www.cvat.ai)، یا Roboflow.
روی هر فرد/کلاه/لباس کادر بکشید و کلاس را بزنید. خروجی را با فرمت **YOLO** بگیرید:

```
export/
  images/a.jpg ...
  labels/a.txt ...    # هر خط: class cx cy w h  (بین ۰ و ۱)
```
عکسی که هیچ‌چیز ندارد را با فایل `.txt` خالی ثبت کنید (پس‌زمینه).

## ۴) آماده‌سازی دیتاست
```bash
python training/prepare_dataset.py --src /path/to/export --val 0.2
```
تقسیم ۸۰/۲۰ انجام می‌شود و `training/dataset/data.yaml` ساخته می‌شود. در پایان تعداد نمونه هر کلاس چاپ می‌شود؛
کلاسی با کمتر از ~۱۰۰ نمونه علامت هشدار می‌گیرد (برای نتیجه خوب، هر کلاس **۳۰۰+** نمونه).

## ۵) آموزش
```bash
# CPU (کند ولی ممکن؛ برای مدل nano و دیتاست کوچک)
python training/train.py --model yolo11n.pt --epochs 80

# GPU انویدیا (توصیه‌شده): مدل دقیق‌تر + نصب خودکار
python training/train.py --model yolo11s.pt --epochs 100 --device 0 --install
```
اگر GPU ندارید، همین دستور را در [Google Colab](https://colab.research.google.com) یا Kaggle (GPU رایگان) اجرا کنید
و فایل `runs/ppe/weights/best.pt` را دانلود کنید.

آموزش از وزن‌های از پیش آموزش‌دیده (COCO) شروع می‌شود (transfer learning)، به همین دلیل با چند صد تصویر هم نتیجه می‌دهد.
اگر ۲۰ epoch متوالی بهبود نبود، خودکار متوقف می‌شود (`--patience`).

## ۶) ارزیابی
```bash
python training/evaluate.py --weights runs/ppe/weights/best.pt
```
برای هر کلاس Precision، Recall و mAP50 چاپ می‌شود. نمودارها و ماتریس درهم‌ریختگی در `training/runs/eval/` هستند.

| معیار | معنی عملی | هدف |
|---|---|---|
| Recall پایین | تخلف را نمی‌بیند (آلارم از دست می‌رود) | > ۰٫۸ |
| Precision پایین | آلارم کاذب زیاد | > ۰٫۸ |
| mAP50 | کیفیت کلی | > ۰٫۸۵ |

اگر دقت کم بود، **قبل از عوض کردن مدل یا پارامتر**، داده را بهتر کنید: نمونه‌هایی که ماتریس درهم‌ریختگی نشان می‌دهد
اشتباه می‌شوند اضافه کنید.

## ۷) نصب مدل در برنامه
```bash
cp runs/ppe/weights/best.pt models/ppe.pt     # (یا --install در مرحله ۵)
python run.py                                  # راه‌اندازی مجدد
```
در داشبورد، پایین منوی کناری باید «مدل PPE فعال» دیده شود، و در «تنظیمات ← وضعیت سیستم» کلاس‌های مدل نمایش داده می‌شوند.

## ۸) سرعت بیشتر روی CPU / GPU
```bash
python training/export.py --format openvino      # CPU اینتل؛ معمولاً ۲ تا ۳ برابر سریع‌تر
python training/export.py --format engine --device 0 --half   # TensorRT
```
سپس `SC_MODEL_PATH=ppe_openvino_model` را در `.env` بگذارید (نام نسبت به پوشه `models/`).

## ۹) تنظیم حساسیت بدون آموزش دوباره
در «تنظیمات»:
- **آستانه اطمینان** را برای کاهش آلارم کاذب بالا ببرید.
- **مدت تخلف** را بیشتر کنید (مثلاً ۵ ثانیه) تا لحظه‌ای که فرد کلاه را درست می‌کند آلارم نشود.
- **حداقل ارتفاع فرد** را بالا ببرید تا افراد خیلی دور (که تشخیصشان غیرقابل اعتماد است) نادیده گرفته شوند.

## ۱۰) بررسی سالم بودن اسکریپت‌ها (بدون داده واقعی)
```bash
PYTHONPATH=. python tools/make_synthetic_dataset.py --out /tmp/synth --n 80
python training/prepare_dataset.py --src /tmp/synth
python training/train.py --epochs 2 --batch 8
```
این دیتاست مصنوعی فقط برای تست زنجیره است و مدل خروجی آن برای استفاده واقعی **بی‌ارزش** است.
