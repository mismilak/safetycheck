# سیف‌چک (SafetyCheck) — پایش هوشمند ایمنی کارگاه

سامانه‌ای که به دوربین (وب‌کم، USB یا IP/RTSP) وصل می‌شود، **کلاه ایمنی و لباس کار** افراد را تشخیص می‌دهد،
تخلف‌ها را با عکس شاهد ثبت می‌کند و همه‌چیز را در یک داشبورد فارسی (راست‌چین، فونت وزیرمتن، PWA) نشان می‌دهد.

## امکانات
- **پایش زنده** با کادر رنگی روی هر فرد (سبز ایمن / زرد ناقص / قرمز ناایمن)، لیست افراد و فید آلارم لحظه‌ای (WebSocket)
- **آلارم هوشمند:** ردیابی هر فرد، هموارسازی زمانی (بدون آلارم کاذب با پرش لحظه‌ای تشخیص)، مدت تخلف و فاصله آلارم تکراری قابل تنظیم
- آلارم با **عکس شاهد**، صدا، اعلان مرورگر، تلگرام و Webhook
- **رسیدگی به آلارم** (رسیدگی شد / هشدار کاذب / یادداشت)؛ فریم هشدارهای کاذب برای آموزش مجدد ذخیره می‌شود
- **آمار:** توزیع ساعتی، روند روزانه، نرخ انطباق ایمنی، نوع تخلف، تفکیک دوربین
- **گزارش:** Excel و CSV (تاریخ شمسی) و چاپ/PDF
- **چند دوربین**، هر کدام با قوانین مخصوص خود (الزام کلاه / الزام لباس)
- **احراز هویت و سطوح دسترسی** (۴ نقش) و لاگ ممیزی
- **PWA:** قابل نصب روی موبایل/دسکتاپ، کش آفلاین پوسته برنامه
- **سریع و بدون CDN:** همه کتابخانه‌ها، فونت و آیکون‌ها از خود سرور (کار در شبکه بسته)، فونت ساب‌ست‌شده، Chart.js فقط در صفحه آمار لود می‌شود

## اجرای سریع
نیازمندی: Python 3.10+ (روی لپ‌تاپ خودتان؛ برای وب‌کم باید برنامه مستقیم روی همان دستگاه اجرا شود)

```bash
./start.sh          # Linux / macOS            (Windows: start.bat)
# یا دستی:
pip install -r requirements.txt
python run.py
```
سپس **http://localhost:8000** را باز کنید. در اولین اجرا، نام کاربری `admin` و یک **رمز تصادفی** در کنسول چاپ می‌شود
(یا با `SC_ADMIN_PASSWORD` تعیین کنید). در اولین ورود باید رمز را عوض کنید.

بدون دوربین/مدل هم می‌توانید همه‌چیز را ببینید: `SC_DETECTOR=demo python run.py`
(صحنه شبیه‌سازی‌شده با کارگرانی که کلاه/لباسشان تغییر می‌کند. فقط برای نمایش و تست است).

### مدل تشخیص (مهم)
- **بدون فایل مدل PPE:** برنامه فقط افراد را (با مدل عمومی `yolo11n`) می‌شمارد و وضعیت کلاه/لباس «نامشخص» است؛ **هیچ آلارم کاذبی ساخته نمی‌شود** و داشبورد هشدار می‌دهد.
- **با مدل PPE:** فایل را در `models/ppe.pt` بگذارید. نام کلاس‌ها باید شامل `Hardhat` و `Safety Vest` باشد
  (و اختیاری `NO-Hardhat`، `NO-Safety Vest`، `Person`)؛ نام‌گذاری‌های رایج دیتاست‌های Roboflow/Kaggle پشتیبانی می‌شود.
- **مدل آماده برای شروع سریع:** `python tools/download_ppe_model.py` (YOLOv8s با کلاس‌های Person / Hardhat / NO-Hardhat / Safety Vest / NO-Safety Vest؛
  روی بخش test خودِ دیتاستش: تصمیم «کلاه دارد/ندارد» ≈ ۹۸٪ و «جلیقه دارد/ندارد» ≈ ۱۰۰٪ برای افراد پیداشده؛ روی دوربین شما ممکن است کمتر باشد).
  اگر دانلود نشد، فایل `best.pt` را از [این مخزن](https://github.com/VoxDroid/Construction-Site-Safety-PPE-Detection/tree/main/Model-Training/Outputs/runs/detect/yolov8s_ppe_css_200_epochs/weights) بگیرید و با نام `ppe.pt` در `models/` بگذارید.
  مجوز دیتاست و مدل را قبل از استفاده تجاری بررسی کنید.
- مدل PPE آماده داخل این مخزن **گنجانده نشده**. دو راه: (۱) آموزش مدل مخصوص محیط شما با `training/`
  (**توصیه‌شده**، راهنمای کامل در [`training/README.md`](training/README.md))، یا (۲) استفاده از یک مدل عمومی PPE با مجوز مناسب.

## تنظیمات محیطی (`.env`، نمونه: `.env.example`)
| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `SC_PORT` | 8000 | پورت |
| `SC_ADMIN_USERNAME` / `SC_ADMIN_PASSWORD` | admin / تصادفی | حساب مدیر اولین اجرا |
| `SC_DETECTOR` | auto | `auto` / `yolo` (مدل PPE الزامی) / `demo` |
| `SC_MODEL_PATH` | ppe.pt | نام مدل داخل `models/` (فایل `.pt`/`.onnx` یا پوشه OpenVINO) |

## عیب‌یابی سرعت (fps پایین یا تصویر عقب‌مانده)
تصویر زنده و تشخیص هوشمند دو حلقه‌ی مستقل‌اند: کندی تشخیص فقط تعداد به‌روزرسانی کادرها و آلارم‌ها را کم می‌کند، نه روانی تصویر را.
روی صفحه «پایش زنده» دو عدد می‌بینید: **fps** (روانی تصویر) و **تشخیص N/ث · X میلی‌ثانیه** (زرد اگر بیش از ۳۰۰ms باشد).

برای پیدا کردن گلوگاه، دوربین را جدا از برنامه اندازه بگیرید:
```bash
python tools/benchmark_camera.py --source rtsp://user:pass@192.168.1.20:554/stream1
```
- **capture پایین است** ← مشکل دوربین/دیکد است، نه هوش مصنوعی. معمولاً: استریم اصلی ۴K/۱۰۸۰p و H.265 را روی «زیر‌استریم» (۶۴۰×۳۶۰ یا ۷۲۰p، H.264) بگذارید؛ Wi-Fi را با کابل عوض کنید.
- **inference کند است** ← مدل سبک‌تر (`n`)، `training/export.py --format openvino`، GPU، یا کم کردن «تعداد تشخیص در ثانیه» در تنظیمات.

برای RTSP، برنامه به‌طور پیش‌فرض از TCP و گزینه‌های ضدتأخیر FFmpeg استفاده می‌کند. در صورت نیاز با
`SC_RTSP_OPTIONS="rtsp_transport;udp|fflags;nobuffer|flags;low_delay"` عوضش کنید.

## معماری
```
وب‌کم / RTSP / فایل ─► خواننده/ناشر (آخرین فریم، تا ۲۰fps) ─► MJPEG
                         └─► رشته تشخیص مستقل: YOLO ─► ردیاب IoU ─► ComplianceEngine (قوانین + آلارم)
                                        │                                  │
                                        └── MJPEG ─┐        SQLite + عکس شاهد + اعلان‌ها
                              FastAPI  ◄───────────┴─ WebSocket (آلارم و وضعیت زنده)
                                 │
                       داشبورد PWA (ES Modules، بدون فریم‌ورک)
```
- `app/vision/rules.py` منطق خالص قوانین (ردیابی، انتساب کلاه/لباس به هر فرد، هموارسازی، آلارم) و تست‌شده است
- مستندات API: `http://localhost:8000/api/docs`

## PWA و HTTPS
نصب PWA فقط روی `localhost` یا **HTTPS** ممکن است. برای دسترسی از موبایل در شبکه داخلی، برنامه را پشت یک
reverse proxy با گواهی (مثلاً Caddy / nginx) بگذارید و `SC_COOKIE_SECURE=true` قرار دهید.
مثال Caddy: `safety.example.local { reverse_proxy localhost:8000 }`

## امنیت
رمزها با bcrypt؛ نشست با JWT در کوکی `HttpOnly` + `SameSite=Lax`؛ محافظ CSRF (هدر سفارشی)؛ قفل موقت پس از ۵ تلاش ناموفق؛
CSP سخت‌گیرانه و هدرهای امنیتی؛ کنترل Origin در WebSocket؛ رمز دوربین‌های RTSP برای نقش‌های بدون مجوز مخفی است؛
توکن تلگرام پس از ذخیره دوباره نمایش داده نمی‌شود. بدون HTTPS در شبکه‌ی غیرقابل‌اعتماد استفاده نکنید.

## مجوزها (قبل از فروش حتماً بخوانید)
- **Ultralytics YOLO تحت AGPL-3.0 است.** انتشار/فروش نسخه بسته (closed-source) یا SaaS بدون انتشار کد منبع، نیازمند
  [مجوز تجاری Ultralytics](https://www.ultralytics.com/license) است. معماری این پروژه جداپذیر است
  (`app/vision/detector.py`) و می‌توان آن را با تشخیص‌دهنده‌ای با مجوز آزاد (مثلاً ONNX Runtime + مدل مجوزدار) جایگزین کرد.
- وزیرمتن (OFL)، Chart.js (MIT)، آیکون‌های Lucide (ISC): مجوز و متن آن‌ها در `app/static` همراه فایل‌هاست.
- مجوز داده‌های آموزشی و مدل‌های عمومی PPE را جداگانه بررسی کنید.
- این سیستم **کمک‌ابزار ایمنی** است و جایگزین نظارت انسانی نیست؛ دقت آن به کیفیت دوربین، نور و داده آموزشی بستگی دارد.
  پایش تصویری کارکنان ممکن است نیازمند اطلاع‌رسانی/رضایت طبق قوانین محل شما باشد.
